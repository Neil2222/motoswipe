# Motoroccasion.nl as an evidence source — assessment (2026-09-05)

Read-only investigation. Nothing was imported, stored beyond scratch files, or
republished. About twenty pages were fetched by hand with a two-second pause.

## 1. Site structure

- Server-rendered PHP (`text/html; charset=ISO-8859-1`) behind Cloudflare,
  session cookie `PHPSESSID`, `Cache-control: no-cache`, `Vary: User-Agent`.
  A plain `curl` with a browser User-Agent and with an honest
  `MotoSwipe/0.1` User-Agent both receive the same full page. No bot wall.
- `robots.txt` contains only a `Sitemap:` line — nothing is disallowed.
- `sitemap.xml` (427 URLs): brand index pages, content pages, news. Model
  and listing pages are not in the sitemap.
- Stable IDs in every URL, generated by the Qonnex dealer-inventory platform
  the site runs on:
  - brand: `/motoren/<brand>-b<id>.html` (BMW = b4, Yamaha = b40, Honda = b18,
    Suzuki = b35, Triumph = b37, Kawasaki = b24, CFMOTO = b184)
  - model ("type group"): `/motoren/<brand>-<model>-b<id>-tg<id>.html`
    (R 1250 GS Adventure = tg1414, Z900 = tg1129, MT-07 = tg911,
    MT-09 = tg1013, NC 750 X = tg893, V-Strom DL 650 = tg798,
    Tiger 900 = tg1329, 450 MT = tg2139)
  - variant/type: `…-b<id>-t<id>.html` (e.g. MT-09 SP = t7847)
  - listing: `/motoren/<brand>-<name>-m<id>.html` (m1613692); `og:url` is the
    canonical form, there is no `<link rel=canonical>`.
- Model page: the first 20 listings are in the HTML, **sorted by build year
  ascending**. Each row carries brand, dealer-entered type name, asking price
  ("€ 7.350,-"), "year, km", dealer name with a `data-dlr` id and province,
  and a "Merkdealer" flag. Pagination and filtering run through the site's
  session-bound AJAX search (`motorsearch.js` → `/fs.php`, `/ys.php`,
  `/<session>.php`); the public search form posts to
  `/zoeken/resultaten.html` and returns a shell that is filled the same way.
  **Page 2 onward is not reachable as plain HTML.** No total count is
  printed anywhere.
- Listing page: `Bouwjaar` (build year), `Kleur`, `Vermogen` (often empty),
  `Teller` (km), `Rijbewijs`, `Garantie`, price, lease price, a dealer block
  (`data-dlr`), a free-text description (dealers sometimes write
  "Modeljaar: 2017" in it), and a "Techniek" tab showing Motoroccasion's own
  specification database for the type (power, torque, seat height, dry
  weight, colours). Photographs are signed `cdn.qonnex.com` URLs.
  No JSON-LD, no structured data.

Naming is dealer-entered and inconsistent ("MT 07 ABS", "V-STROM DL 650",
"Z900 70kW"); the type-group id is the reliable model key, the free name is
useful only as an alias/variant hint. Build year is a registration year, not
a model year; a dealer's "Modeljaar" note lives in free text.

Listing counts cannot be reported: only the first 20 rows are served as HTML
and no total is printed. Everything above "20" would require the site's
private AJAX search, which this investigation deliberately did not call.

## 3. What it could support

| Use                                                            | Verdict                                                                                                                                                                                            |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Used-market availability (model on sale second-hand in NL now) | **Yes, strong** — dealer stock with build years, updated live                                                                                                                                      |
| Used asking-price range / median                               | **Yes, with caveats** — asking prices, dealer-only, first page biased to the oldest bikes; must be labelled "dealer asking price, observed <date>", never MSRP                                     |
| Generation-year validation                                     | **Weak** — the site has no generation concept; build years per type group can confirm that a model was sold from year X (R 1250 GS Adventure: earliest build year 2019), not where a restyle falls |
| Variant aliases                                                | **Modest** — "70kW", "ABS", "DCT", "Y-AMT", "GT PRO/LOW", "Black Rhino", type-group splits for DCT/Y-AMT                                                                                           |
| Market popularity                                              | **Weak** — no counts without the AJAX search; the RDW registration data already answers this better                                                                                                |
| Specifications, photographs, descriptions                      | **No** — the "Techniek" tab is Motoroccasion's own compiled database; photographs and texts are dealer/Qonnex content                                                                              |

## 4. Legal and usage constraints

- Disclaimer (`/contact/disclaimer.html`, Motoroccasion B.V.): _"Zonder
  schriftelijke toestemming van Motoroccasion mag niets van Motoroccasion
  gekopieerd worden."_ — nothing may be copied without written permission.
  No separate terms page, no API or data-partner page, no mention of
  automated access. `robots.txt` allows everything; the disclaimer does not.
- Photographs: signed CDN URLs (`cdn.qonnex.com/…?signature=`) — cannot be
  hotlinked durably and must not be stored.
- Dealer names, descriptions and the specification tab are third-party or
  compiled content: not to be reproduced.
- Conclusion: reading a handful of public pages to _derive aggregates_ is
  ordinary web use; a production scraper that stores per-listing data is
  "copying" in the disclaimer's words. Written permission (or a feed through
  Qonnex, which supplies the dealers' inventories) should be requested before
  anything runs on a schedule.

## 5. Technical load

- Pages are plain server-rendered HTML; one GET per model page, ~150 KB,
  no JavaScript needed for the first 20 rows. Pagination needs the private
  AJAX search and should not be used.
- A conservative fetch: one request per 2–3 s, first page only, at most a
  few hundred model pages per run, weekly. `Cache-control: no-cache`, so
  cache on our side by `tg` id and date. Honest User-Agent with contact.
- No bot protection was encountered and none should be circumvented.

## 6. Architecture proposal (only after permission)

`MotoroccasionProvider` as a **MARKET_EVIDENCE** provider, never a
specification or image provider, feeding a new `MarketObservation` table:

| Field                                           | Source                                                                                               |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| `familyKey` / canonical model candidate         | curated map `tg<id>` → catalogue family (like `official-pages.ts`; never guessed from the free name) |
| `sourceUrl`                                     | the type-group page URL (provenance)                                                                 |
| `observedAt`                                    | fetch date                                                                                           |
| `sampleSize`                                    | rows read (≤ 20, or the full count if permission covers the search)                                  |
| `buildYearHistogram`                            | `{2019: 20}`                                                                                         |
| `askingPriceEur` min / p25 / median / p75 / max | from the rows                                                                                        |
| `mileageKmMedian`                               | from the rows                                                                                        |
| `dealerCount`, `brandDealerShare`               | distinct `data-dlr`, "Merkdealer" flag                                                               |
| `newStockCount`                                 | rows with build year ≥ current year and km < 100                                                     |
| `variantNames`                                  | distinct dealer-entered type names (for alias curation, reviewed by hand)                            |

Persist aggregates per (family, observation date) only. Do not persist
listing ids, photographs, descriptions, dealer names or prices per listing.
Card copy: "Used examples on offer in NL (dealer asking prices, observed
2026-09): from €13,900" — clearly separated from MSRP.

Discovery eligibility must not depend on it: `availableUsed` would be an
extra, labelled fact, not an evidence gate.

## 7. Special case: BMW R 1250 GS Adventure

- The type group exists (tg1414), is distinct from the R 1200 (tg755) and
  R 1300 (tg1597) GS Adventure, and its first page already holds 20 dealer
  listings, all build year 2019, €13,936–20,450, median mileage ≈41,700 km.
  More listings exist beyond page 1 (later years).
- This confirms an **active Dutch used market** and that the R 1250 GS
  Adventure's first build year in dealer stock is 2019, consistent with the
  catalogue's 2018–2025 generation (2018 being pre-registration of the 2019
  model year).
- It does **not** solve the card's actual problem: the card is excluded for
  want of a photograph, and Motoroccasion's photographs cannot be used.
  Generation validation here is a sanity check, not new evidence.

## Verdict

- **Worth integrating?** Only with written permission, and only as market
  evidence. Without permission: no.
- **Trust for:** used-market presence, build-year span of dealer stock,
  dealer asking-price bands (labelled as such), km bands, variant-name hints.
- **Never trust for:** MSRP, model year (build year ≠ model year),
  generation boundaries, specifications, categories, images.
- **Persist:** per-family aggregates with `observedAt` and the type-group
  URL; a curated `tg` → family map.
- **Never copy:** photographs (signed CDN), descriptions, the "Techniek"
  specification tab, dealer names/contacts, per-listing records.
- **Estimated value:** medium for the product ("is this bike easy to find
  second-hand, and for roughly what?"), low for the catalogue's evidence
  gaps — it adds no images and no generation boundaries. Coverage would be
  near-complete for mainstream models (every test model has a type group;
  even the CFMOTO 450MT has four dealer listings).
- **Ask permission first:** yes. Send a short request to Motoroccasion B.V.
  (contact form) describing a weekly first-page read of ~300 model pages,
  aggregates only, with attribution; ask whether they or Qonnex offer a feed.
