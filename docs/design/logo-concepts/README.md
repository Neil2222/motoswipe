The concept PNGs and `../apex-heart-preview.png` are local design references excluded from Git and the Docker build context. A fresh clone contains the production SVGs, app icons and the prompts below; it does not contain these preview images.

- 02-v-twin-love.png: V-twin engine with a heart-shaped silhouette.

The production source is `static/brand/apex-heart.svg`. It preserves the helmet and heart visor as flat orange geometry with transparent cut-outs. Run `npm run icons:generate` after changing this source to regenerate the favicon SVGs and all PNG sizes, including legacy filenames. The app and manifest use `apex-heart` filenames to distinguish the new artwork from cached old icons. The service worker already rotates its cache per build.

`../apex-heart-preview.png` shows the finished mark, app icon, circular Android mask and small sizes. Apple and maskable icons have opaque square backgrounds for the OS to crop. The Android mark is inset to fit within the central safe circle. On narrow phones, the header shows the symbol with an accessible MotoSwipe label; wider screens include the wordmark.
